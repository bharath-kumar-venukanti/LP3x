## Features
- **Live In-Browser Execution:** Run scripts and inspect output logs in real-time.
- **Categorized Problem Solving:** Async retries, string manipulations, arrays, closures, and DOM checks.
- **Search & Filter:** Instantly filter programs by tags, keywords, or topics.
- **Responsive UI:** Custom dark/light mode toggle built with vanilla HTML/CSS/JS.
