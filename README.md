# JS & TS Practical Exercises & Demos

A practical repository containing hands-on implementations, code snippets, and automation demos using JavaScript and TypeScript.

## 🚀 Key Features & Learning Focus
* **JavaScript Fundamentals:** Core syntax, asynchronous programming, DOM manipulation, and ES6+ features.
* **TypeScript Integration:** Type annotations, interfaces, generics, and strict type-checking setup.
* **Test Automation:** E2E testing demos using Playwright.

## 🛠️ Tech Stack & Tools
* **Languages:** JavaScript (ES6+), TypeScript
* **Test Runner / Framework:** Playwright
* **Runtime:** Node.js
